# Proposed slices 09–13

These are independent of the deferred [Slice 07 NVIDIA validation](07-nvidia-telemetry.md)
(`nht-f456db`). No implementation has started.

| Slice | What to ship | What proves it works |
|---|---|---|
| **09 — Linux cgroup workload totals** | Extend [Slice 08](08-workload-resource-use.md) with an on-demand summary for the cgroup v2 containing a selected PID. Study Below and Tasklens. Use kernel `cpu.stat` and `memory.current`; distinguish charged cgroup memory from summed process RSS. No command lines, environment values, or elevation. | Compare against the live cgroup files as an unprivileged user. Test nested accounting, cgroup recreation, missing controllers, and PID movement between samples. |
| **10 — Recorder coverage and history gaps** | Extend [Slice 01](01-sampling-gaps.md) to handle missing *rows*, not just missing readings in existing rows. Show the latest sample age and visible breaks across long intervals in CLI and TUI history. Label gaps as unobserved time, not recorder failures; manual samples and cadence changes are valid. | Render fixtures for hourly, bursty, mixed-cadence, and overnight data. Check that CLI and TUI agree, stored values stay unchanged, and a missing interval is distinct from zero. |
| **11 — Live per-interface throughput** | Build on [Slice 04](04-live-network-rates.md) to show which local interface is busy. Compare GPUI Metrics Monitor and NetWatch-alt's presentation. Preserve the strict host aggregate and each interface's valid directions independently. Start with live output; no packet capture, remote scans, or unbounded history. | Test first sight, reset, rename/removal and idle zero; verify Linux and macOS live counters. Show that one interface's reset does not wipe other interfaces' valid rates. |
| **12 — On-demand disk topology** | Follow [Slice 03](03-device-disk-history.md) and iodyne. Explain partition/parent and virtual-device relationships in current inventory where the OS exposes them. Keep discovery out of the sampling path. Do not regroup historical rows by current topology or expose serial numbers. | Compare Linux and macOS inventory against native read-only tools. Test virtual, unplugged, and unknown devices, and verify that `record` does not enumerate topology. |
| **13 — Read-only Linux energy** | Study Siomon's RAPL collector and Linux powercap. Start with explicitly named package domains, read accessible energy counters and derive watts with monotonic timing. Keep powercap package watts distinct from hwmon channel power and omit intervals where resets or wraps cannot be resolved. No permission changes or privileged helper. | Test units, zero, wrap/reset ambiguity and permissions. Validate readings on a real Linux host with readable powercap counters before claiming support; identify that host early. |

Start with Slice 09. For each slice, inspect the reference source before
implementing, document metric semantics and platform limits, and checkpoint
the evidence. Run the existing test, type-check, and build recipes, plus a
rendered TUI smoke where the display changes.
